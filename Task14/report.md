При ленивой загрузке SQLAlchemy в цикле даёт N+1: один запрос за авторами плюс по одному на книги каждого. На большом числе авторов это долго — число запросов растёт линейно. Заметил так: "for a in authors: len(a.books)" → в логе 1 SELECT по authors и 5 по books.
Каждый запрос — это отдельный round-trip к БД, что дороже объёма данных.

Права в Linux — это три группы по три бита: владелец, группа, остальные. Каждая группа может иметь r (4), w (2), x (1). 644 — владелец читает и пишет, остальные только читают. 755 — владелец ещё и выполняет. x нужен для программ и каталогов (чтобы войти в них), но не для конфигов. chmod 600 на .env — чтобы только владелец мог читать секреты. Своими глазами видел: после chmod -x hello.sh скрипт перестал запускаться — Permission denied.
